## Purpose

This folder contains the planning and implementation documents for Phase 1 of Raj Hamal's professional portfolio website.

Phase 1 is a premium, content-driven portfolio. It does NOT include a custom CMS, Supabase backend, authentication, or an AI chatbot.

Phase 2 can add a Supabase-backed CMS/admin system after the frontend and content architecture are stable.

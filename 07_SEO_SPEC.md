# SEO Specification

## Domain

https://rajhamal.com.np

## Homepage title

Raj Hamal | Data Analyst | Applied AI & Data Analytics

## Homepage description

Create a concise, factual description describing Raj Hamal as a postgraduate student in Applied Artificial Intelligence and Data Analytics at the University of Bradford, with previous operations experience and independent data analytics projects.

## Core topics

- Raj Hamal
- Data Analyst
- Applied AI
- Data Analytics
- Business Analytics
- Business Intelligence
- Tableau
- Data Analytics Portfolio
- Bradford UK

Do not keyword stuff.

## Required

- unique title per page
- unique meta description
- canonical URL
- Open Graph
- Twitter metadata
- sitemap.xml
- robots.txt
- JSON-LD
- semantic headings
- descriptive image alt text
- project-specific metadata

## Structured data

Use appropriate schema types where accurate:

- Person
- WebSite
- BreadcrumbList
- CreativeWork / Article for appropriate case studies

Do not create fake Organization or employer data.

All public portfolio pages should be indexable unless there is a specific reason not to.

Do not index future `/admin` routes if Phase 2 adds them.

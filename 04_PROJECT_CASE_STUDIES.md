# Project Case Study Specification

Every project page should use a consistent analytical case-study structure.

## Standard structure

1. Project hero
2. Short overview
3. Project metadata
4. Business/research question
5. Dataset
6. Data preparation
7. Methodology
8. Analysis
9. Visualizations
10. Key findings
11. Business implications/recommendations
12. Tools
13. GitHub
14. Live dashboard where available
15. Related projects

Do not show empty sections.
